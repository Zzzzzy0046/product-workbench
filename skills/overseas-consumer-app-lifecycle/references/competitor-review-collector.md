# 竞品评论采集器调用说明

## 定位

桌面版 `竞品信号工坊` 是新品工作流中的可选证据采集工具，负责获取竞品 Google Play / App Store 评论原文及其元数据。

它不是 Product KB，也不是新品判断器。它的结果进入当前项目的 T1 / A2，不直接进入正式知识库。

## 什么时候调用

仅在以下情况调用：

- 需要验证竞品用户真实反馈；
- 需要比较不同国家或地区的评论差异；
- 需要寻找竞品功能、稳定性、广告与付费或信任问题；
- 用户提供了 package ID、App Store ID 或商店链接，并希望抓取评论。

如果用户只要求市场概览、竞品功能或政策资料，不必启动评论采集器。

## 调用边界

- 默认只做评论抓取和原文核验；
- 默认不勾选 DeepSeek 语义分析；
- 默认不启用 App Store 评论翻译；翻译会把原文发送到外部翻译服务，必须单独确认；
- 工具抓取完成后可能自动生成本地规则预览；该预览不作为最终产品结论，可以忽略；
- 不把评论频率当成全量用户比例；
- 不把抓取市场当成评论作者所在地；
- 不把评分分布当成文本情感；
- 不自动把原始评论写入 Product KB。

## 输入

- 平台：Google Play 或 App Store；
- 应用标识：package ID、App Store ID 或商店链接；
- 市场列表；
- 每市场请求上限；
- 排序方式；
- 开始和结束日期；
- 是否需要翻译（默认否）。

## 输出

优先保留：

- 原始评论；
- 翻译文本（如果明确确认）；
- 评论 ID；
- 评分；
- 版本；
- 抓取市场；
- 评论日期；
- 点赞数；
- 开发者回复；
- 抓取批次和来源。

导出 CSV / XLSX 后，交给 T1 的用户分析和竞品分析使用，并在 A2 记录抓取时间、市场、样本量和限制。

## 失败处理

- 没有 package ID / App Store ID：先补齐标识，不猜包名；
- 单个市场失败：保留其他成功市场，并记录失败原因；
- 结果为空：不要覆盖上一次有效批次；
- 工具不可用：使用用户提供的 CSV / XLSX，或转为 Web 只读证据采集；
- 抓取成功但 AI 分析失败：保留原始评论，不能把分析失败当成抓取失败。
