# 交付检查

`aw build` 自动做：地图结构校验、证据文件存在性、状态截图有效性/重复、流程图 PNG 完整性、`flow_notes.md` 存在、Word 表格残留（如有 Word）、未确认动作提醒。结果写入 `delivery_review.md`。**PASS 只说明文件和引用有效。**

## 人工必查

- 打开至少一张正常流程图和一张有分支/缺图的流程图：箭头的源、目标、动作文字对不对；橙色广告/外跳标注是否符合你的观察。
- 模块状态：`complete` 有覆盖说明；`partial/blocked/skipped` 写了原因，没有被隐藏。
- 所选路径是否走到结果页；没走到的写原因（登录、订阅、权限、广告阻断、设备限制）。
- 商业化（如在范围内）：paywall 出现位置与时机、价格/试用/默认套餐/CTA、Remove Ads 入口、评分弹窗时机、广告类型与时机——只写实际看到的。
- 双设备：每台设备单独 `--out`、单独地图；跨端关系在结论里另外说明。
- 隐私：分享的 PNG/Word 中不得出现真实账号、手机号、邮箱、精确位置、支付信息；有就先打码。

## 最终回复包含

1. 流程图路径（`flow_export/`）与模块列表。
2. 覆盖情况与缺口（未覆盖/阻塞及原因、广告是否曝光、网络环境）。
3. 用户要分析时：简短结论，事实与推断分开。
4. 证据目录 `observations/`、地图 `research-map.json` / `app-map.md` 作为追溯信息。
