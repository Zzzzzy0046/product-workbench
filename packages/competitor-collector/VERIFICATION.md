- 独立包有自己的 `.venv`；安装后 `pip check` 无冲突，不依赖原工作台数据库或桌面旧工具。
- Python 代码编译、JavaScript `node --check`、PowerShell 启动脚本语法检查通过。
- 后端与相邻工作台回归：277 项通过、1 项跳过。跳过项为当前 Windows 账户无法创建真实符号链接；模拟 symlink/junction 与越界检查均有通过用例。
- 最后一次 CLI 安全错误提示和 Excel 前导空白公式防护调整后，40 项相关请求/导出/CLI/来源字段测试通过；PowerShell 5 原生命令引号处理已实际执行检查，正式实例仍未创建默认管理员。
- 旧工作台 worker 保留原 CLI/私有函数和 JSON 协议，现由独立包共享核心实现。
- 为旧工作台实际使用的桌面虚拟环境补装了 Pillow，避免剥离后截图校验因缺依赖而失败；没有改变它的账号或采集配置。
- 一个既有 10 毫秒缓存过期测试在全套运行时受机器负载影响，改为测试局部的可控单调时钟，未改变缓存生产行为。

权限回归覆盖：未登录、普通成员、管理员；普通成员的任务列表/详情/单文件/ZIP 归属校验；payload 伪造 owner/role 无效；成员不能管理账号；停用后旧会话和下载失效；来源与 CSRF 校验；密码及会话不明文存储；最后管理员保护；登录限流；会话过期。

失败和路径回归覆盖：磁盘/目录错误不会让任务永久 running；重启不自动重试；缺失/坏图/超大图；图片域名与重定向限制；链接目录/路径穿越不会进入其他任务；源码包与资料 ZIP 不包含账号库或运行凭证。

## 真实商店小样本

在隔离测试账号和输出目录，通过浏览器提交：

- 应用：Pizza Boy A: GBA Emulator（`it.dbtecno.pizzaboygba`）
- 市场：US
- 条数：5
- 开启：商店信息、评论、商店截图
- 关闭：翻译及付费模型

实际结果为 5 条评论、6 张商店截图，长短描述正常显示；图片放大及 CSV、ZIP 浏览器下载成功。6 张图实际解码为 287×512。测试没有把正式实例的管理员替你设置成测试账号。

浏览器验证登录、管理员面板展开、国家下拉、高级筛选、结果表格、图片放大、退出清理和刷新后仍未登录。390px 窄屏已截图检查无明显横向溢出；桌面 CDP 截图偶发超时，桌面以 DOM、尺寸、真实加载和下载为主要证据，没有宣称所有桌面画面均完成截图审查。
