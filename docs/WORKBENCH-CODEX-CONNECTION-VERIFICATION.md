# Codex 连接面板：实现与验证记录

日期：2026-10-22｜版本：ProductWorkbench 2026.10.22.4

## 交付内容

- “能力与工具”顶部新增连接面板，支持自动发现、候选选择、完整本机 `codex.exe` 路径、恢复自动检测。
- CLI 可用、登录状态和生成测试三个状态独立显示；仅浏览页面不会触发登录或模型请求。
- 浏览器登录须单独确认；使用官方 CLI 的固定 `login` 命令，工作台不接收账号密码，也不读取或复制登录缓存。
- 连接测试须另行确认额度提示。只在临时空目录发送固定文本“仅回复连接成功”，不传项目、评论或截图，关闭工具与网络搜索能力。
- 登录与测试可取消；进程实际停止前继续显示处理中。文档生成、自动截图与改变 CLI/登录/测试之间设置互斥，避免中途切换账户或路径。
- 仅保存本机 CLI 路径偏好，不进入项目导出。重启后不会把上次登录检测或模型测试结果当作当前已验证。
- 对拒绝的少量 HTTP 请求体限时排空后关闭连接，修复 Windows 下 403 偶发连接重置；仍在授权检查通过后才解析、分派请求。

## 使用者仍需自行验证

- 在本人电脑安装或选择 Codex CLI，并在官方页面登录自己的账号。
- 如需确认实际模型可用，自行确认后执行“连接测试”；成功仅代表当次最小请求成功，不代表所有项目任务、模型或配额长期可用。
- 本轮没有执行真实账户登录或真实模型请求；没有全新 Windows 虚拟机、同事电脑或真实目标 App 全范围验收。

使用步骤见随包《Codex连接与首次使用.md》。CLI 的登录凭据仍由 Codex 自己管理，不应将凭据发给同事。
