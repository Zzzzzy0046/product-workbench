# 工作台 Android 实机截图走查

更新日期：2026-10-22。当前后端：`android-walkthrough 1.0.1`，JSON 协议 v1。

## 用法

资料 → 实机截图走查 → 选择设备、填写 App 包名与走查范围 → 开始自动走查 → 预览模块流程 PNG → 确认加入项目资料。

范围可以直接写：「只走查首次进入、导入文件和回到首页，记录正常、取消和失败状态；暂不看订阅与设置」。系统不会要求你手工标注每一次点击。模型先根据实际控件判断，必要时读取同一观察的缩略图；新版 Skill 负责单步执行、证据、地图与模块拼图。

只有一台在线设备时自动选中；多台需要选择 serial。App 必须已安装，开始前只读核对包名和版本。范围内需要启动 App 时由工具启动，不安装、不清数据。首次未找到 ADB 时在窗口配置路径；`WORKBENCH_ADB_PATH` 也可指定。EXE 内置 Python、Skill 与解析导出依赖；源码运行才需单独安装 Python 依赖。两者均需本机 ADB、Codex CLI 登录和支持图像/工具调用的模型。

## 自动执行与人工接管

- 本轮预算为 60 次设备动作、10 分钟；超时有额外的有限收尾与进程清理时间。
- 观察截图与 UI 绑定同一次 observation；点击或输入前重新核对前台、可操作结构及目标当前语义，不因观察只有几秒就跳过校验。过时索引、无证据跳转被拒绝。
- 系统权限、选择器、登录、绑定、购买/试用和敏感输入由用户处理。窗口显示暂停原因，手机处理后继续。
- 停止会写取消标记并结束子进程；进程尚未退出时不能同设备重开，也不能删除关联项目。
- 继续时为新 attempt，重置本轮预算并保留历史累计、地图、编号和原始证据；先重新观察当前位置，不重发上次点击。
- 服务重启后运行中的记录改为 interrupted。项目包导入同样不会自动重新操作设备。

## 结果与资料

默认展示模块流程 PNG、原始截图、模块覆盖状态与缺口。结果在确认之前不会自动进入资料检索。确认后导入实机图、流程图和包含 `asset://` 图片引用的走查索引，绑定创建任务时的项目和产品版本。

未覆盖模块与中断路径保持未完成；部分证据也可在用户确认后入库，索引保留暂停/阻塞原因。商店宣传图、实机截图与模型生成内容不混称为同类证据。

会话目录：

```text
workbench/data/scrapes/<project_id>/android-<session_id>/
  session.json                 工作台任务与确认状态
  request.json                 当前本机执行配置，不通过图片接口公开
  aw.json                      新版工作区配置，不通过图片接口公开
  capture-session.json         观察断点
  capture-tool-state.json      每轮与累计预算
  research-map.json            已观察模块、页面、状态与真实跳转
  observations/                原始 PNG/XML/JSON 与按需读取的 view.jpg
  flow_export/                 模块流程 PNG 与说明
  flow-manifest.json           当前导出清单
  agent-result.json            完成/暂停/阻塞及交付检查
  progress.jsonl               工具执行进度，无模型推理
  timings.jsonl                实际设备调用与耗时
  attempts/                    本机诊断，项目导出时排除
```

会话包含在既有项目 ZIP 与回收站机制中。导出会清理本机 ADB/Python/skill 路径、缓存、动画设置备份和执行连接字段，保留设备身份、包名、版本、真实截图和地图；导入重映射项目、产品版本、会话和资料 ID，必须人工续跑并重新观察。

## 执行结构

前端沿用原生 JavaScript 与现有资料页；服务沿用当前进程和 SQLite。无需新增网站、前端构建器或后台服务。

单独的 Codex runner 只注入当前会话的截图 MCP，使用本机当前模型和连接白名单，关闭通用 shell、浏览器、其他插件与多代理功能。12 个固定 MCP 工具提供观察、受限 tap/tap-xy/text/back/swipe、已有观察缩略图、证据地图和导出；不提供敏感确认覆盖、动画设置、任意命令或任意文件路径。原有文档生成 runner 保持原约束。EXE 固定使用随包 Skill，不读取个人 D 盘目录。

CLI 使用 stdio MCP、工具 allow list 和超时配置，参数依据[官方 MCP 文档](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)及[配置参考](https://learn.chatgpt.com/docs/config-file/config-reference)，并以本机 CLI 帮助核对实际支持。

## 验证边界

自动化使用合成截图、FakeAdb 和临时项目，验证新鲜度、敏感动作拦截、真实相邻跳转、模块覆盖、暂停续跑、取消/并发、显式入库、项目迁移、图片路径和 runner 连接约束。当前 EXE 的实际冻结验证结果以 [EXE 验证记录](WORKBENCH-EXE-VERIFICATION.md) 为准，不把模拟设备操作等同于真实手机覆盖。

历史版本曾做一次真实 Codex CLI 连接冒烟：仅暴露 capture_context 与 finish 两个工具，读取合成任务并按「无设备、无真实截图」返回 blocked。该历史记录不代表本次新版已经执行真实模型或真实 App 走查。

浏览器检查使用隔离服务和合成资料，覆盖资料页入口、ADB 配置提示、草稿保留、暂停/ready 详情、PNG 加载、下载及确认入口；未在本轮替用户指定真实 App 或操作设备。实际走查应以选定 App、设备和范围的真实结果为准。
