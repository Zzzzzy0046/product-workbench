# 公司快速交付 PRD 模板 v1.0

> **历史模板提示：** 本模板已在 v2.0 中拆分为新品立项、新品 PRD、迭代 PRD 和快速需求单四类。新需求请从 [PRD文档体系-v2.0.md](./PRD文档体系-v2.0.md) 选择，不再默认使用本模板。

> 适用：小团队的新品、功能迭代、体验优化和商业化需求。
>
> 目标：产品、设计、研发、测试用一份文档完成对齐并开始交付。
>
> 负责人：产品经理是 PRD 的作者和最终责任人，负责产品目标、范围、优先级、流程、业务规则和验收结果。Agent 只能在产品初稿基础上检查、整理和补漏，不能代替产品做决策。
>
> 规则：固定章节保留；不涉及就写“不涉及”；没结论就写“待确认 + 负责人”，不能让 Agent 或执行人员默认补成已确认需求。

### 目标用户与核心场景

| 项目 | 内容 |
|---|---|
| 目标用户 | 谁最需要解决这个问题 |
| 触发场景 | 用户在什么情况下产生需求 |
| 当前做法 | 用户现在如何解决或绕过问题 |
