## 1. 为什么做

### 一句话需求

为需要在近距离寻找蓝牙设备的 Android 用户，在设备遗落于附近但无法快速定位时，通过 Bluetooth 扫描和相对信号强弱反馈，帮助用户缩小寻找范围。

### 背景与问题

- 当前问题：普通 Bluetooth 设备可能没有专属找回 App，用户只能反复查看系统蓝牙列表，无法持续获得接近反馈。
- 用户证据：`产品假设`。当前只有竞品页面参考，尚无正式用户访谈和数据。
- 为什么现在做：先验证“扫描附近设备 → 选择目标 → 根据相对信号查找”的核心路径是否容易理解。
- 不做的影响：无法判断用户是否愿意使用独立工具完成近距离设备找回。

### 目标与判断标准

- 用户目标：在不知道设备准确位置时，快速发现并靠近目标设备。
- 业务目标：验证近距离 Bluetooth 找物工具是否具备可用的核心场景。
- 本版本要验证：用户能否理解信号强弱，并完成扫描、选设备、开始查找和结束任务。
- 上线后优先观察：权限完成率、扫描启动率、扫描发现设备率、进入 Find Nearby 比例、主动标记找到比例。
- 数值目标：`待确认：产品负责人；首个测试版本形成基线后补充。`

## 3. 用户流程

### 首次使用

```text
Onboarding
→ Permission Setup
→ Home
→ Scan Results
→ Device Detail
→ Find Nearby
→ Mark as Found / Stop
```

### 非首次使用

```text
Home
├→ Scan Nearby → Scan Results → Device Detail → Find Nearby
└→ Saved Devices → Find Nearby
```

### 失败与恢复

```text
权限未授予 → 发起系统授权 → 回到 App 重新检查
权限永久拒绝 → Open Settings → 回到 App 重新检查
Bluetooth 未开启 → 进入系统处理 → 回到 App 重新检查
扫描无结果 → 提示检查距离与设备状态 → Retry
查找中断开 → 保留当前目标 → Retry / Stop
```

### 中断规则

- 首版只支持前台扫描，不定义后台持续扫描。
- 用户离开扫描任务后停止本次前台扫描。
- 当次动态扫描列表只在当前会话保留。
- 已保存设备与符合写入条件的历史记录保存在本机。

## 5. 页面与功能需求

### P01 Onboarding

- 页面目的：用 3 张静态画板分别说明发现附近设备、根据信号靠近、保存常用设备。
- 进入条件：仅首次启动且未完成引导时进入。
- 页面模块：插画占位、标题、简短说明、进度指示、Continue/Get Started。
- 关键交互：前两页 Continue 进入下一页；最后一页 Get Started 记录引导完成并进入 P02。
- 边界：不表达地图、精确距离、方向、Apple Find My 或让目标设备发声。
- 验收：完成后再次启动不重复进入；引导完成不代表权限和 Bluetooth 已就绪。

### P02 Permission Setup

- 页面目的：展示扫描所需条件，并提供可恢复的下一步。
- 状态：未授权、拒绝后需去设置、权限及系统能力已就绪。
- 页面模块：准备项列表、当前状态、说明文字、主按钮。
- 关键交互：Continue 发起系统授权；Open Settings 进入 Android 设置；Start Scanning 进入 P03。
- 系统规则：App 只发起系统请求；回流后重新读取实际状态，不在 App 内伪造成功。
- 待研发确认：不同 Android 版本的准确权限组合、Bluetooth 开启方式和系统回调。

### P03 Home

- 页面目的：作为扫描和历史任务的主要入口。
- 页面模块：扫描主操作、当前扫描反馈、附近结果摘要、最近设备、Saved Devices 入口、底部主导航。
- 状态：默认可扫描、扫描中、有结果、无结果。
- 关键交互：Scan Nearby 开始前台扫描；有结果时进入 P04；无结果时允许 Retry。
- 数据规则：设备名称、信号级别和发现时间来自当次扫描；原型数据仅为占位。
- 边界：不承诺支持所有 Bluetooth 设备，不把信号强度换算为真实距离。

### P04 Scan Results

- 页面目的：让用户从当次扫描结果中选择目标设备。
- 页面模块：结果数量、排序/筛选、设备列表、信号等级、Refresh、Find。
- 状态：扫描中、有结果、无结果。
- 关键交互：选择设备进入 P05；Refresh 开始一次新扫描并替换当前动态列表。
- 数据规则：排序和筛选只作用于当次扫描结果。
- 边界：设备可能没有可读名称，需显示通用占位名称；不显示精确米数。

### P05 Device Detail

- 页面目的：核对设备信息、保存为常用设备并进入近距离查找。
- 页面模块：设备名称、设备类别、信号等级、最后发现时间、备注、Save Device、Find Nearby。
- 状态：未保存、已保存。
- 关键交互：保存后写入本地设备记录；编辑名称、类别和备注只修改 App 本地数据；Find Nearby 进入 P06。
- 边界：保存不等于 Bluetooth 配对或绑定，不修改外部设备。
- 删除规则：删除保存记录不删除历史记录，也不影响系统或外部设备数据。

### P06 Find Nearby

- 页面目的：持续展示相对信号变化，帮助用户靠近目标。
- 页面模块：目标设备摘要、信号反馈区、状态说明、Stop、Retry、Mark as Found。
- 状态：搜索中、信号弱、接近、连接/广播断开。
- 关键交互：Stop 结束任务；断开后 Retry；Mark as Found 结束任务并写入成功历史。
- 反馈规则：声音和震动均为手机本机反馈，具体节奏待设计与研发确认。
- 边界：不显示精确距离、方向或 UWB 能力，不表示可以让目标设备发声。

### P07 Saved Devices

- 页面目的：快速再次查找已保存的常用设备。
- 页面模块：设备列表、名称、类别、最后发现信息、Find、管理入口、空状态 CTA。
- 状态：有保存设备、空状态。
- 关键交互：Find 进入 P06；管理进入 P05；空状态引导用户前往扫描。
- 数据规则：本地保存，不包含账号、云同步、家庭共享或多端同步。
- 失败规则：重命名或移除失败时保留操作前数据，不显示虚假成功。

### P08 History

- 页面目的：查看曾产生结果的扫描及已完成的查找任务。
- 页面模块：按时间排列的记录、记录类型、设备信息、Find Again、Clear。
- 状态：有记录、空状态、清除确认。
- 写入规则：有扫描结果的任务可以写入；用户确认找到的任务写入；无结果且中途取消的任务不写入。
- 清除规则：Clear 二次确认后只删除本机历史，不删除 Saved Devices。
- 关键交互：Find Again 使用记录中的目标重新进入 P06；目标不可用时展示失败和重新扫描入口。

### P09 Settings & Help

- 页面目的：管理 App 自身反馈方式，并提供权限恢复和使用帮助。
- 页面模块：声音反馈、震动反馈、权限状态、Open Settings、使用说明、故障排查、隐私入口。
- 状态：默认、权限或系统能力异常。
- 数据规则：声音和震动开关作为新建查找任务的默认值，不追溯修改已经开始的任务。
- 权限规则：状态来自 Android 系统实时读取；Open Settings 跳转系统设置，回流后再次检查。
- 边界：本页不提供账号、云同步、订阅和广告设置。

## 6. 公共规则与边界

### 业务和数据

- 当次扫描结果：仅在当前会话保留，刷新后替换。
- Saved Device：保存名称、类别、备注及用于再次识别的本地设备引用。
- History：保存符合写入条件的扫描或查找摘要。
- 删除 Saved Device 不删除 History；清空 History 不删除 Saved Device。
- 首版所有产品数据仅保存在本机，不提供账号、云同步和多端同步。

### 权限与系统能力

- 需要 Bluetooth 扫描及对应 Android 版本要求的系统权限。
- `待研发确认`：最低 Android 版本、准确权限名称、Bluetooth 关闭时是否可直接请求开启。
- 权限拒绝后保留说明和再次申请入口；永久拒绝后引导 Open Settings。
- 系统设置回流后重新读取状态，不默认视为已授权。

### 商业化

- 本版本不涉及广告、订阅或 IAP。
- 不预留不可见 Paywall，也不在核心扫描与查找流程插入商业化页面。

### 隐私与政策

- 产品只申请实现附近扫描所必需的权限。
- 首版不上传扫描到的设备信息，不采集远程位置和账户数据。
- 需要在隐私政策与 Google Play Data Safety 中如实说明 Bluetooth/附近设备相关数据用途。
- `待研发确认`：第三方 SDK 是否读取或上传设备、位置或诊断信息。

## 7. 验收与交付

### 核心验收标准

| 验收 ID | Given | When | Then | 优先级 |
|---|---|---|---|---|
| AC-01 | 首次启动且引导未完成 | 用户完成最后一张引导 | 记录引导完成并进入权限准备 | P0 |
| AC-02 | 权限或 Bluetooth 未就绪 | 用户完成系统处理并回到 App | App 重新读取状态并展示真实结果 | P0 |
| AC-03 | 扫描条件已满足 | 用户点击 Scan Nearby | 展示扫描中，并最终进入结果或无结果状态 | P0 |
| AC-04 | 扫描发现至少一个设备 | 用户选择设备 | 展示该设备详情，不混入其他设备数据 | P0 |
| AC-05 | 用户正在查找目标设备 | 相对信号发生变化 | 页面更新为对应信号状态，不显示虚构精确距离 | P0 |
| AC-06 | 用户保存设备 | 保存成功 | Saved Devices 可查看该记录，App 重启后仍保留 | P0 |
| AC-07 | History 中存在记录 | 用户确认 Clear | 只清除历史，Saved Devices 保留 | P1 |
| AC-08 | 权限已永久拒绝 | 用户点击 Open Settings | 打开正确的 App 系统设置，回流后重新检查 | P0 |

### 交付范围

- 设计：9 个功能页及 26 个低保真状态画板对应的正式 UI。
- Android：前台扫描、权限与系统状态读取、本地设备/历史数据、信号反馈和页面流程。
- 测试：权限分支、扫描结果、无结果、断开、数据保存/删除、系统设置回流和 App 重启恢复。
- 数据：先设计核心漏斗埋点，事件名称和参数进入独立埋点文档。
- 上线观察：权限完成、扫描结果、开始查找、标记找到和异常退出。
- 降级：无法扫描时保留权限检查、故障排查和退出路径，不显示虚假设备结果。
