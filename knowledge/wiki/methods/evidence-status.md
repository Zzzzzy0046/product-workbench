# 证据状态

- `[事实]`：有可追溯的来源、数据、原型或真实行为。
- `[推断]`：由事实推导，必须写清推导链。
- `[假设]`：尚未验证，不得包装成行业结论。
- `[决策]`：影响目标、范围、资源或实现的明确选择。
- `[风险]`：可能影响价值、采用、可行性、商业或合规。
- `[待确认]`：当前缺失但不阻断其余工作的输入。

证据强度分层：指导性规则、静态文件验证、本地 Mock、真实构建、真机行为、真实 API 或真实数据。低层证据不能冒充高层验证。
