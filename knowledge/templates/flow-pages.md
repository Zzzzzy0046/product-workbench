# 功能流程与页面状态清单

同一份交付物先说明流程，再按需要给定位清单。依据当前用户确认及指定基线 [Sx]，从本轮模块继续；已有 ID 和确认流程沿用，只补本轮变化，不为模板新增账号、设置、功能或独立异常页。当前草图或实现与约定不同的地方保留差异，不自动当作规则已改变。

## 本轮范围与依据

产品 / 版本、当前阶段、包含及不包含模块、实际读取的原型或文件 [Sx]。没有可读取原型时标明此为页面方案，不能声称与原型逐页核对。

## 分模块功能流程

### [模块中文名]

入口 → 前置条件 → 用户操作 → 关键结果 → 下一页或返回来源。

- 成功：用户看到什么、数据或权益如何改变、可继续做什么。
- 失败 / 取消 / 中断：仅保留本模块实际需要的分支，明确回哪里、保留什么、如何恢复。
- 公共规则：RULE-xx；关键位置、图示或原型引用 [Sx]。

只对本轮需要说明的模块重复。已有确认流程时引用原位置并列本轮变化，不重新生成全产品流程；公共规则仅引用既有正文，业务值变更使用同轮唯一变更表中的 REV / RULE。简单流程可用文字或 Mermaid；不得仅凭静态截图声称交互已验证。

## 页面与状态清单

已有编号表且编号、归属和路径未变时，引用现有位置即可，不重新输出全量清单。首次梳理，或本轮新增、删除、改变归属/路径时，才使用下表列出相关项。只有明确要求完整清单时才汇总全量现有项，不重新发明编号。

| 稳定 ID / 中文名 | 类型 | 基础页 / 所属模块 | 进入来源与触发 | 退出 / 返回 | 必须表达的状态 | 规则与原型位置 |
|---|---|---|---|---|---|---|
| 沿用项目编号 | 页面 / 弹窗 / 局部状态 / 系统说明 | | | | | RULE-xx / [Sx] |

编号不随排布重排，删除后检查引用。小幅选中、禁用和文案变化附在基础页，只写变化的内容、控件和反馈，不复制整页说明；页面正文以当前指定的旁注或 PRD 页面说明为同一来源。系统支付、权限和文件选择器说明触发、保留的来源背景与返回即可，不默认重画。
