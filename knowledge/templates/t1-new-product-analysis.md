# T1 新品需求分析

> 默认正式交付物。用户已经指定品类时，不再用机会门阻断流程；按“市场 → 用户 → 竞品 → 定位 → MVP → 流程 → 商业化 → 政策 → 预研 → 指标 → 执行决策”推进。

## 使用规则

- 正文默认使用中文；保留必要的技术术语、平台名称和英文 UI copy。
- 每个关键结论标记 `[事实]`、`[推断]`、`[假设]`、`[决策]`、`[风险]` 或 `[待验证]`。
- 当前市场、竞品、价格、政策和系统能力必须保留来源、地区、平台、日期和口径。
- 用户指定的品类默认继续完成 0–12 章；证据不足时写成假设、风险、验证任务、范围收窄条件或后续 Kill Criteria。
- 不包含付费投放、媒体采买、投放归因、ASO 文案、商店素材和商店发布执行。
