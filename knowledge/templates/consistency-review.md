# 全局一致性检查

按本轮实际读取资料比较当前原型、旁注、PRD、流程、编号、公共规则和验收预期。优先围绕本轮已变更的规则与页面说明核对，输出可定位的新增冲突和替换建议，不重写全量需求。只有文件名、时间或“正式”字样不能证明内容一致；历史送审快照不能覆盖当前用户确认。

## 本轮核对范围

| 资料 / 版本 | 实际读取范围与来源 | 用途与当前性 | 未核验部分 |
|---|---|---|---|
| | [Sx] | 当前基线 / 参考 / 历史快照 | |

采用当前用户确认及指定基线。原型或实现说明实际表现，已确认文档说明约定规则，草图或实现偏差不自动覆盖约定；没有明确决定时保留冲突，不凭新旧自行选择一方。仅有节选时写明实际页/章节及未核对部分，不把片段比较当成全量检查。

## 对照结果

本轮跨产物变更只维护一张表。已有 REV / RULE 变更表时，只给对应项的补充文本和本次新发现的差异，不复制完整同步状态；未实际写回该表时仍标待同步。没有既有表时，下表作为本轮唯一对照表。无新差异只简述已核对范围，不逐项罗列“无差异”或填空表。

| 关联变更 / 新问题标识 | 主题与具体页面 / 章节 | 各来源当前写法与旧口径残留 | 旧口径 → 本次已确认新口径 / 待决定 | 受影响产物及本轮核对范围 | 修订建议 / 实际写回证据或待同步 |
|---|---|---|---|---|---|
| 沿用 REV / RULE；新问题才用 CHECK-xx | 不只填文档名称 | 当前原文及 [Sx]；未提供处写未核对 | 已有确认则引用，未确认不当作决定 | 只列实际涉及页面、规则、文件章节 | 未实际写回则待同步 |

检查实际涉及的范围、免费与付费权益、额度及有效期、计算顺序、广告触发与奖励结果、数据保留、取消返回、编号、页面文案、失效引用、后置功能残留等；无关项省略。用已确认新口径逐处对照旧数值、旧顺序、旧去向及等义表达，不能只搜一个关键词就认定无残留，也不能因数份文件同名/同日期就认定已同步。验收预期需对应新规则，而非继续验证已废弃行为。

原型旁注与 F2 应沿用同一份页面正文及稳定 ID；若各自被改成不同说法，只提出对应段落的最小替换，不再生成第三份页面说明。画面核对包括本轮变动区域、完整 UI 文案、背景保留与新增反馈；无法访问画面时不声称检查遮挡与可见性。

## 可交接内容与遗留项

引用本轮唯一变更表，简述哪些范围已对照、哪些仍未核对或待决定/待同步，以及下一步最小行动，不另建管理文档。未发现差异只表示本次读取范围内未发现；给出修订文本不代表已写回原型或其他文件，不推定 App 已实现、测试通过、初审或终审通过。需要改正文时给出对应替换位置，沿用意见修订中的同一份页面正文。
