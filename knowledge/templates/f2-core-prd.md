# F2 原型与需求说明

按本轮模块与范围整理当前原型及对应需求。原型旁注与 F2 共用同一份页面说明正文：已有指定或确认文本时沿用页面 ID、业务主题与原文，仅补本轮变化，不各自自由改写；需要完整 PRD 时汇入同一份正文并合并已确认变化。没有原型时交付页面方案与说明草稿，明确尚未落到原型。支持直接从当前阶段进入，不强制先重做 F1，也不以固定页数或篇幅裁掉必要规则。

资料采用：当前用户确认及指定基线优先；原型或实现用于说明实际表现，已确认文档用于说明约定规则，草图或实现偏差不自动覆盖约定。两者不一致时列出具体位置，没有明确决定前保留差异；历史记录与通用模板只作参考。未读取的原型、未执行的写入与测试不能写成已完成。旧稿只作对照，不恢复已后置或已删除功能。正文中文，必要 UI copy 保留项目语言。

## 1. 模块流程与页面索引

按主流程或导航顺序组织模块，先写入口 → 操作 → 结果 → 后续去向，再写必要失败、取消和中断恢复。已有确认流程与页面清单时引用其具体位置，仅列本轮新增、删除、归属或路径变化，不重复输出下面的全量索引。首次梳理或明确要求完整索引时才使用下表，沿用现有编号与确认内容。

| 页面 ID / 中文名 | 类型与归属 | 进入来源 | 退出 / 返回 | 必须表达的状态 | 原型位置 / 来源 |
|---|---|---|---|---|---|
| 使用项目既有稳定 ID | 页面 / 弹窗 / 局部状态 / 系统说明 | | | | [Sx] |

编号不随排版整体重排，局部状态不当作新增功能。简单选中和文案变化只补差异；复杂异步、多条件或中断恢复按需补状态表。

## 2. 分模块页面与需求说明

本节是与原型旁注共用的页面说明正文。已有正文时只处理授权的页面/主题变化，未涉及部分原文保留；仅交局部修订时给出替换位置与完整替换段落，交完整 PRD 时合并这些变化，不要求读者再打开其他设计文件才能理解。首次补齐页面或新增页面时采用下面要点，按业务灵活合并，不强制每页重复所有栏目。

### [页面 ID] [中文页面名] · [必要状态名]

页面用途与呈现：说明独立页 / 弹窗 / 局部状态 / 系统说明、基础页及原型位置 [Sx]。写明示例初始状态、保留的来源背景、遮罩及新增反馈所在位置；简单状态只写与基础页不同的部分。

布局与内容：按位置和层级说明区域在哪里、包含哪些控件、主次关系，以及滚动/固定区域、默认项和必要留白。界面应在文中可理解，不用“见原型”替代关键内容；当前资料没有覆盖的布局写缺口，不反向编造成已确认画面。

界面文案：保留当前涉及的完整标题、按钮、页签、提示及输入占位文字，固定文案与动态示例分清。复杂页面按需用“区域 / 控件—界面原文”表核对，普通页面随布局和操作写清，不额外重复表格。

按业务内容选择小标题，例如“内容展示”“输入与保存”“广告与奖励”“关闭与返回”；不强制每页套相同栏目。不适用项删除。

① [业务主题]

1、从什么入口进入，在什么条件下展示什么、默认选中什么。
2、用户点击哪个控件，何种条件允许，处理后原页如何变化或去哪个页面 ID。

② [业务主题]

1、成功、失败、取消或系统返回分别如何处理，保留或清除哪些数据。
2、重复操作、外部返回或中断恢复确实影响本页时，说明结果与可继续操作。

公共规则：引用 RULE-xx 或已确认标题，只补本页触发、表现与例外。

参考与竞品差异（按需）：同一模块集中说明有 [Sx] 支持的可见内容、借鉴点与当前产品选择；本页确有新的不同取舍时才补充，不给每个弹窗、Toast 或状态重复对标段落，不从参考图推断隐藏规则。

资源需求（按需）：制作内容、数量、复用关系。待确认（按需）：具体缺口、影响范围与待决策内容。

按本轮需要新增或修改的页面重复，保留“① 业务主题 / 1、说明”的写法。若确认规则与实际画面不同，明确标出待同步的位置；不能为表面一致而把画面偏差改写成已确认规则。

## 4. 同步与研发交接

本轮跨产物变更只维护一张表。已有意见修订或公共规则中的变更表时引用其 REV / RULE 和位置，本节只交代尚需研发处理的具体项，不重复同步状态。没有既有表且本轮确有变化时才使用下表；没有变化则省略表格。

| 变更标识 / 旧口径 → 本次已确认新口径 | 确认依据 | 受影响产物的具体页面 / 章节 | 本轮核对范围与旧口径残留 | 当前已写回 / 待同步 |
|---|---|---|---|---|
| 沿用 REV / RULE | [Sx]；未确认不当作决定 | 只列实际受影响的位置 | 已核对、残留原文或未核对部分 | 未执行的外部原型或文件修改写“待同步” |

提交前按变更口径核对受影响的画面、说明、流程、编号、公共规则与验收预期，检查旧数值、旧顺序、旧去向及等义表达是否残留；缺少当前资料的位置写“未核对”，不以文件名或旧快照代替当前正文。涉及外部原型的实际修改、结构回读、截图检查、真机运行分别报告；只生成替换正文而未写回对象时仍写待同步，不能宣布全局已更新或评审通过。只输出本轮需要的交接内容，不强制接着生成埋点或验收，也不额外创建管理报告。
