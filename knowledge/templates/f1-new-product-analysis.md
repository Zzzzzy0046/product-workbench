## 9. 产品主要流程

### 9.1 启动与首次使用

```text
启动 → 必要说明或权限 → 核心入口 → 完成第一次任务 → 得到结果
```

### 9.2 核心任务流程

```text
触发需求 → 进入功能 → 完成操作 → 结果反馈 → 保存 / 分享 / 继续
```

### 9.3 再次使用流程

```text
再次进入 → 恢复上次状态或看到新结果 → 继续核心任务
```

### 9.4 商业化流程

```text
先完成核心价值 → 在合适节点展示权益或广告 → 用户主动购买 / 关闭 / 继续
```

补充会改变产品路径的必要分支；不要在 F1 穷举所有 Loading、Empty、Error 和控件状态。
