# 公共规则

只集中整理影响多个页面的当前规则，已有规则沿用原 ID。当前用户确认及其指定基线优先；原型或实现用于说明实际表现，已确认文档用于说明约定规则，草图或实现偏差不自动覆盖约定。两者有差异时列出具体位置，未有明确决定前不自行取舍，也不把意图当成已落实行为。缺少决定就写具体待决定项，不补造价格、额度、时长或能力。

## 本轮范围与依据

产品 / 版本、本轮模块、采用的原型或文档 [Sx]、用户确认及本轮停止位置。历史版本只作差异核对，不恢复已后置内容；只提供节选时写明已读取章节，不把节选当成整份资料已核对。

## 公共规则表

| 规则 ID | 当前规则 | 触发 / 生效 / 失效条件 | 例外、失败与恢复 | 涉及页面 | 依据与确认情况 |
|---|---|---|---|---|---|
| RULE-xx | | | | 中文名＋稳定 ID | [Sx] / 当前确认 / 待决定 |

按实际涉及内容填写免费限制、广告与奖励、购买权益、数据保存、共享返回和恢复等规则。已有公共规则来源时沿用确认文本，只补本轮变化；同一规则只维护一份正文，各页面引用 RULE-xx 并补本页触发、表现与例外，不在多处各写一套数值和生效条件。广告和订阅业务值来自本项目，案例不能成为默认值。

## 本轮冲突与同步

本轮跨产物变更只维护一张表。已有意见修订或其他交付物中的变更表时，引用其 REV / RULE 和具体位置，只补新发现的差异，不再复制同步状态；没有既有表且确有规则变化时，才在此使用下表。没有变化或冲突则省略，不输出空表。

| 变更标识 / 旧口径 → 本次已确认新口径 | 确认依据 | 受影响产物及具体页面 / 章节 | 本轮核对范围与旧口径残留 | 已写回位置 / 待同步 |
|---|---|---|---|---|
| 沿用 REV / RULE | [Sx]；尚未确认则保留差异 | 画面、旁注、PRD、流程、编号或验收中实际涉及的位置 | 已读位置、残留原文或未核对部分 | 无实际写回证据则待同步 |

变更顺序：确认新规则 → 列影响范围 → 改规则正文 → 同步受影响产物 → 核对旧口径及其等义表达是否残留 → 复查相关流程与验收预期。只有当前资料覆盖且实际完成的修改或核对才记录结果；未提供的页面或文件写“未核对”，只交修订文本而未写回外部对象时写“待同步”，不得预填完成。无需另外创建变更管理文档。
