# 原型制作交接与旁注草稿

为当前外部原型制作整理可执行内容，原型旁注与 F2 使用同一份页面说明正文。已有指定或确认的页面说明时，沿用原 ID、业务主题和确认文本，仅给本轮授权变化及制作要求，不另写第二套同义说明。此任务在工作台内交付文档；实际 Figma / Axure 写入与视觉核验需由连接器或操作者另行执行。没有执行证据时统一标明“待制作 / 待同步”，不能写已创建画面或已完成视觉检查。

## 交接范围与基线

产品 / 版本、当前阶段、实际可访问原型或资料 [Sx]、本轮模块、现有组件及允许修改范围。注明本轮沿用的页面说明来源及位置；当前用户确认及指定基线优先，画面或实现与约定不同处列明，不自动覆盖已确认规则。当前正式方案一套，后置与历史稿分区，不恢复旧业务规则。

## 模块与排布

按主流程或导航组织模块：模块标题 → 流程概览 → 必要模块规则 → 页面与说明成对摆放。已有流程和规则引用原位置，不再次编写一套正文。图文单元上方显示“稳定 ID＋中文名＋必要状态”，左画面、右需求说明、顶部对齐；说明高度随内容增长。已有项目布局与组件优先复用；仅调整局部时，下表只列本轮受影响页面，不重建全量制作清单。

| 页面 ID / 中文名 | 本轮制作或调整 | 参考位置 / 组件 | 同页状态表达 | 当前落实情况 |
|---|---|---|---|---|
| | | [Sx] | 简单差异附基础页，关键变化给局部示例 | 待制作 / 待同步 |

## 逐页旁注草稿

以下写法用于首次补齐页面说明或新增页面。已有正文时仅输出指定页面/主题的替换段落或新增内容，其他确认文本保持不变。用户要求完整交接稿时，复用同一份正文并合并已确认变化，不重新自由改写。说明应让操作者不打开其他设计文件也能理解页面与交互；简单状态只写相对基础页的差异，不逐页复制所有栏目。

### [稳定 ID] [中文名] · [状态]

页面是什么：简述用途，说明独立页 / 弹窗 / 局部状态 / 系统说明及基础页；弹窗保留哪一页背景、是否遮罩，成功或失败反馈新增在哪里。

布局与内容：按从上到下、从左到右说明区域位置、包含的控件与主次关系，写清滚动与固定区域、默认内容和选中项。已有布局只写本轮变化，不靠“同参考图”代替必要说明，不擅自指定资料未确认的视觉细节。

界面文案：保留本轮涉及的完整标题、按钮、页签和提示原文，区分固定文案与动态示例。复杂页面或文字易遗漏时按区域列文案核对表；简单页面直接随控件说明，不额外复制一张表。

① [业务主题]

1、何种条件进入与展示，默认内容或选中项。
2、用户操作 → 原页变化或目标 ID → 数据与权益结果。

② [业务主题]

1、必要的关闭、取消、系统返回及输入保留行为。
2、必要失败、重复操作或中断恢复；引用 RULE-xx，避免复制公共规则。

资源需求（按需）：对象、数量与复用关系。待确认（按需）：具体问题及影响。

以上要点按业务合并为易读段落与“① 业务主题 / 1、说明”，不强制每页重复一整套栏目。需求中文，必要 UI copy 按项目语言。竞品参考与差异在确有取舍时按模块集中说明，本页只有新增差异才补充。系统界面只注明系统接管、触发、来源背景与返回，不自动制作自定义替代页。

## 执行后的核对点

仅列本轮确有需要的执行核对。跨产物变更状态引用同轮唯一变更表中的 REV / RULE 及页面或章节，不另建一套同步状态表；此处只记录实际执行的制作核对证据，尚未执行写待执行。

| 核对对象 | 应核对什么 | 当前证据 / 待执行 |
|---|---|---|
| 图与说明 | 按钮文案、默认项、跳转、规则、编号一致 | 无实际核验则写待执行 |
| 图面可读性 | 文字可见、无截断遮挡、长页与固定区关系清楚 | 需要实际截图或原型查看 |
| 跨模块 | 公共规则、返回来源与状态归属一致 | 对照当前基线 |

结构读取不能替代截图查看，静态原型检查不能替代真机验收；只报告实际执行的验证层级。缺少当前原型或文档时标明未核对范围；修订正文已给出但未写回其他对象时仍为待同步，不据此宣布规则已全局更新。
