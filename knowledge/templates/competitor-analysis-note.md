只记录已有资料，不强迫每款查全或深度体验，不凑竞品数量。已选定则直接记参考范围；未确认仍是候选。角色可为主对标、局部功能参考、商业化参考、暂不选择，数据缺失不自动淘汰。

近期下载与累计安装区间不能混比；收入区分商店内购 / 订阅 / 付费下载、广告、合计或未知，注明估算 / 实际数据来源、币种、净毛口径、地区与周期。缺失不写 0，不能从安装量推算收入，也不能把商店收入当总收入。同名免费版、付费版与不同平台按 ID 区分；口径不齐或资料冲突时保留差别，不强行排名。

实际体验注明应用版本、日期、走过的路径、观察结果和截图位置。仅看商店或宣传图就如实写，不推断隐藏规则或声称已验证；只补查会改变取舍的关键问题，不扩大成一整套研究。
