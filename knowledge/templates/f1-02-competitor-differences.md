# F1-2 竞品差异

> 围绕用户指定或确认的候选，先辅助取舍，再拆解需要参考的竞品。不自动扩大候选或替用户决定选谁，不强迫查全数据。商店长短描述、截图、评论、已有市场数据和实际体验记录按各自能证明的范围使用；没有资料的不补写。

## 4. 竞品分析与差异

### 4.1 候选取舍与选用范围

先用一张轻量表整理已有候选。数量随用户输入与本轮问题决定，不凑固定数量；已经选定时直接记录选用范围，不重做筛选。

| 候选 / 平台 / 应用 ID | 近期下载 / 累计安装 | 收入与覆盖范围 | 本次体验或资料范围 | 建议与用户选用 / 理由 | 地区、周期、来源与记录日期 |
|---|---|---|---|---|---|
|  | 未提供 | 未提供 / 覆盖未知 | 商店描述 / 截图 / 评论 / 实际体验 | 待用户选择 |  |

- 近期下载注明具体统计周期，累计安装区间单列含义；两者不混比，不从安装量推算收入。同名免费版、付费版和不同平台按应用 ID 区分。
- 收入注明商店内购 / 订阅 / 付费下载、广告、合计或覆盖未知，以及估算 / 实际数据来源、币种、净额 / 毛额或未知。缺失不写 0，商店收入不冒充总收入；不同地区、周期或口径不直接排名。
- 实际体验只记录已走的路径、应用版本 / 日期、看到的结果与截图位置；仅看商店或宣传图就如实写，不能声称已体验隐藏规则。无需每款都深度体验，优先补会改变取舍的关键问题。
- 选用角色可为主对标、局部功能参考、商业化参考、暂不选择。建议与用户最终选择分开；未确认仍保留为候选，数据缺失不自动淘汰。
- 只填已有数据；需要进一步核对时写清核对什么及为何影响取舍，不启动一整套研究或强制查齐。资料冲突保留具体来源，不按文件名或数值大小选一个。
