# 完整工作流的范围边界

当前完整工作流覆盖：市场与用户判断、竞品证据、产品定位、MVP、PRD、原型交付、商业化设计、预研、埋点、QA 和研发验收。

研发验收完成后进入 `ACCEPTED_HANDOFF`。只有项目已经存在真实产品数据时，才按需进入产品指标、留存、商业化表现和版本迭代诊断。

明确排除：付费获客、媒体采买、投放归因、ASO 文案、商店素材、Google Play/App Store 上架、灰度发布、版本发布和商店回滚。

快速 F1 不输出平台、权限、数据或政策章节。只有具体 PRD 页面或验收项确实依赖系统权限时，才在对应功能中写必要规则；完整研究模式仍可按明确要求进行专项政策检查。
